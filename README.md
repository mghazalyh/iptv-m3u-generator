# IPTV M3U Generator for Windows 10

This repo is a simplified Windows 10 setup for a self-hosted IPTV source checker that can generate an M3U/M3U8 playlist for your own player.

What this repo does:
- downloads/clones the upstream Guovin/iptv-api project into `vendor/iptv-api`
- runs it with Docker Desktop on Windows 10
- lets you start everything with one PowerShell script
- lets you install it as a Windows service after testing

Important:
- GitHub is not the host for live IPTV streams.
- This runs locally on your Windows PC or a Windows server with Docker Desktop installed.
- The upstream project is mostly Chinese-language, but it is still usable.

Quick start:
1. Open PowerShell as Administrator.
2. From the repo root run:
   ```powershell
   .\scripts\install.ps1
   ```
3. Start the app:
   ```powershell
   .\scripts\start.ps1
   ```
4. When you are happy with it, install it as a Windows service:
   ```powershell
   .\scripts\install-service.ps1
   ```

Notes:
- The final M3U/M3U8 output is generated by the upstream project inside its working folder.
- For the exact port and output folder, check the Guovin project or the Docker logs after startup.
- Use browser translation if needed.
